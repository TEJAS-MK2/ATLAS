# Getting Help

## First steps

1. Read the [README](../README.md) for capabilities, setup, deployment, and known service limitations.
2. Review [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the application structure.
3. Check existing [issues](https://github.com/TEJAS-MK2/ATLAS/issues) for a known problem.

## Report a reproducible bug

Open a [bug report](https://github.com/TEJAS-MK2/ATLAS/issues/new?template=bug_report.yml) with:
- Browser and operating system versions.
- Device class and viewport size.
- Exact steps to reproduce.
- Expected and actual behaviour.
- Console/network errors with secrets and personal data removed.

## Request a feature

Use the [feature request form](https://github.com/TEJAS-MK2/ATLAS/issues/new?template=feature_request.yml). Explain the use case and the problem the feature should solve.

## Security issues

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Service limitations

ATLAS uses public third-party map, search, routing, and OpenStreetMap data services. Their coverage, rate limits, uptime, and terms are controlled by their respective providers. A provider outage may affect a feature without indicating an ATLAS application defect.
